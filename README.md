# 血糖血压记录应用

这是一个 Go 标准库实现的小型表格应用，用来查看和补录血糖、血压记录。应用会按每天的时间段展示数据：早上、中午、下午、晚上。

## 功能

- 公开仓库不内置真实健康数据，避免误上传隐私记录。
- 自动解析动态血糖、扎手指血糖、血压和心率。
- 按月份、日期、时间段筛选。
- 每天一行，每个时间段一格，方便横向查看。
- 支持新增手动记录，数据保存到 `data/records.json`。
- 支持导出当前筛选结果为 CSV 和 XLSX。
- 支持导入 XLSX，重复记录会自动跳过。
- 支持手机端自适应界面，日期会以卡片形式按时间段展示。
- 解析原始文本时会对明显日期手误做整理，并在页面显示提醒。
- GitHub Actions 会在 `main` 分支推送后自动运行 Go 测试和 Docker 构建。

## 参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `ADDR` | `:6644` | Web 服务监听地址 |
| `DATA_PATH` | `data/records.json` | 本地持久化 JSON 数据文件 |

## 本地运行

```powershell
go run .
```

打开：

```text
http://localhost:6644
```

## Docker 运行

```powershell
docker compose up -d --build
```

打开：

```text
http://localhost:6644
```

停止：

```powershell
docker compose down
```

## 数据说明

首次启动时会生成 `data/records.json`。之后新增、删除、导入记录都会写入这个文件。`data/`、`*.csv`、`*.xls`、`*.xlsx` 已加入忽略列表，避免把真实健康数据提交到仓库。

XLSX 导入需要包含这些列名中的至少“日期”列，并建议使用应用导出的模板列：日期、时间、时间段、动态血糖、扎手指血糖、未标注血糖、收缩压、舒张压、心率、备注。
